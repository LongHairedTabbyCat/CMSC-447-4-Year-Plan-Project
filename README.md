# CMSC-447-4-Year-Plan-Project

## About this copy

This is a mirror of a team project built for CMSC 447 (Software Engineering)
at UMBC. The original repository is private and owned by a teammate I'm no
longer in contact with, so I can't change its visibility. I mirrored it here
with the full commit history intact, so every contributor's commits remain
attributed to them.

Original: `ksoehnl1/CMSC-447-4-Year-Plan-Project` (private)

### My contributions

This was a team project. My work was concentrated in the following areas:

- **React frontend features:** course search and filtering, drag-and-drop
  scheduling, expandable course detail views, dark mode, and PDF export/import.
- **Validation logic in Flask:** prerequisite combination checking,
  credit-load limits, and degree requirement tracking.
- **Frontend/backend integration:** wiring the React client to the Flask REST
  API, including the prerequisite-checking endpoints.

Four year plan group project for CMSC 447 Section 4.
