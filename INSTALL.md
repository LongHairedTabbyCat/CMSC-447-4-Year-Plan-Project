# Installation

**NOTE**: This installation is for **WINDOWS ONLY**. If you're working on a different machine, then I will help you with that separate installation if needed.

First, install the latest version of [Python](https://www.python.org/downloads/) if you don't already have it.

Then install the latest version of [Node.js](https://nodejs.org/).

For the installation of [MySQL](https://dev.mysql.com/downloads/), I recommend following [this](https://www.youtube.com/watch?v=wgRwITQHszU) tutorial video on YouTube.

**IMPORTANT**: Make sure that Python and MySQL are in your system's **PATH**.

Once installed, clone the repo (or download it if you don't have Git) and run the setup script:  

```sh
git clone 
cd project
setup.bat
```
